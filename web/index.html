ПОДКЛЮЧЕНИЕ

Автоматическая проверка Яндекса

Без сохранения секретных токенов в браузере

01

Добавьте проект на GitHub

Загрузите файлы комплекта в репозиторий. В настройках Pages выберите источник GitHub Actions.

02

Дайте доступ к Яндекс Вебмастеру

Создайте OAuth-приложение для доступа к API Вебмастера, выдайте доступ к данным сайта. Токен сохраните в GitHub → Settings → Secrets and variables → Actions под именем YANDEX_TOKEN.

Официальная инструкция Яндекса ↗
03

Запустите первый сбор

GitHub → Actions → SEO-Радар — позиции и публикация → Run workflow. Далее проверки запланированы ежедневно около 07:12 по Калининграду.

04

Установите на Android

Откройте адрес GitHub Pages в Chrome на Samsung → меню ⋮ → Установить приложение или Добавить на главный экран.

ИСТОЧНИК ДАННЫХ
Яндекс Вебмастер API 4

Среднее место показа, показы, клики по запросам. Два региона и два типа устройства. Данные за последние две недели при каждом сборе.

Документация API ↗
БЕЗОПАСНОСТЬ
Токен только в секретах

Не присылайте OAuth-токен в чат. Он нужен лишь серверному запуску GitHub Actions и никогда не встраивается в HTML-приложение.

ОГРАНИЧЕНИЯ
Google и уведомления

Google пока не подключён. Веб-версия сама не проверяет выдачу в фоновом режиме: ежедневный сбор выполняет GitHub Actions. Push-уведомления без сервера не реализованы.
