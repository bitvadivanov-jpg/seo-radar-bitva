# SEO-Радар «Битва диванов» — мобильное приложение с автоматическим мониторингом Яндекса

**Версия:** 1.0  
**Сайт:** битвадиванов.рф  
**Регионы:** Калининград (22) и Калининградская область (10857)  
**Устройства:** мобильные и компьютер  
**Данные:** средняя позиция показа (возможно дробная), показы и клики из официального API Яндекс Вебмастера.

Это **PWA-приложение**, которое можно установить на главный экран Android и открыть без адресной строки. Это **не APK**: для установки требуется один раз опубликовать веб-приложение на HTTPS. После установки интерфейс может открываться без интернета, но новые замеры собираются только при работающем серверном расписании.

## Как запустить на Samsung прямо сейчас, без подключения

Откройте файл **`SEO_Радар_ПРОСМОТР_НА_ТЕЛЕФОНЕ.html`** в Chrome или Samsung Internet. В нём доступен весь интерфейс, переключатели и список запросов, но реальные позиции пока отсутствуют. Одиночный HTML не может организовать ежедневный фоновый сбор.

## Как запустить с ежедневным автоматическим обновлением

1. Создайте аккаунт GitHub (если ещё нет) и **публичный** репозиторий `seo-radar-bitva`. Загрузите в него **содержимое** папки `SEO_Radar_Android_GitHub`, включая скрытую папку `.github`, **не один ZIP как файл**. Основная ветка должна называться `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Это включит HTTPS-публикацию.
3. В том аккаунте Яндекса, где ваш сайт подтверждён в Вебмастере, создайте OAuth-приложение по официальной [инструкции](https://yandex.ru/dev/webmaster/doc/ru/tasks/how-to-get-oauth). Для приложения укажите доступы API Вебмастера (`webmaster:hostinfo` и `webmaster:verify`). Получите OAuth-токен.
4. В GitHub откройте **Settings → Secrets and variables → Actions → New repository secret**. Name: `YANDEX_TOKEN`; Secret: OAuth-токен. **Не добавляйте токен в файлы проекта или сообщения.**
5. Откройте **Actions → SEO-Радар — позиции и публикация → Run workflow**. Первый запуск заполнит позиции, по которым Яндекс располагает статистикой, и опубликует PWA. Если в Вебмастере нет подходящих показов, появится «—», а не фиктивная позиция.
6. Откройте опубликованный адрес вида `https://ВАШ-ЛОГИН.github.io/seo-radar-bitva/` в Chrome на Samsung. Меню **⋮ → Установить приложение** либо **Добавить на главный экран**. Появится фирменная иконка SEO-Радара.
7. Автоматический запуск настроен примерно на **07:12 по Калининграду** каждый день (05:12 UTC). GitHub иногда задерживает плановые задания. Если сервис выключил плановые задания из-за неактивности, их нужно включить снова в Actions.

**Важно:** данные GitHub Pages публичны — опубликованные поисковые фразы и статистику сможет увидеть любой, кто знает адрес страницы. OAuth-токен остаётся закрытым в секретах GitHub. Если нужны приватные данные только для сотрудников, потребуется альтернативный защищённый хостинг с авторизацией.

## Быстрая публикация интерфейса без автоматического сбора

Для быстрой установки можно загрузить папку `web` на HTTPS-хостинг статических сайтов (например, Netlify Drop). Затем открыть выданный адрес в Chrome и выбрать **Установить приложение**. В этом случае **автоматический сбор не запустится**, пока не будет отдельного планировщика и настроенного источника данных.

## Что делает программа

- Каждый день отправляет запросы в официальный API Яндекс Вебмастера по каждому запросу, региону и устройству.
- Получает данные за последние две недели и сохраняет историю до 120 дней.
- Показывает ТОП-3, ТОП-10, падения на 3+ средних позиции, график, показы, клики.
- Открывает историю по нажатию на строку и выгружает CSV.
- Не придумывает позиции для запросов, у которых Яндекс не вернул статистику.
- Не хранит и не выдаёт токен в браузер.

### Ограничения

- API Вебмастера возвращает **среднюю позицию показа**, не фиксированную позицию на сегодняшней странице выдачи.
- Для некоторых фраз данные могут отсутствовать. Это не то же самое, что «сайт за ТОП-100».
- Google **не подключён**. Для него понадобится отдельный источник данных с региональной детализацией.
- Конкуренты и push-уведомления пока не подключены.
- GitHub Pages — публичный сайт; он не подходит для секретной бизнес-аналитики.
- Этот архив — готовый проект для развёртывания. Настоящий APK в нём отсутствует.

## Изменение списка запросов

Файл `config/keywords.json` содержит стартовые 21 фразу. Добавляйте элементы в формате:

```json
{"query":"где отметить корпоратив в калининграде","group":"Корпоративы"}
```

Не указывайте в этом файле токены или ключи доступа. Сохраните изменения в репозитории: появится новый запуск и список обновится на сайте.

## Техническая структура

- `web/` — PWA, интерфейс, иконки, данные и Service Worker.
- `scripts/check_positions.py` — сбор статистики через официальный API без внешних Python-зависимостей.
- `.github/workflows/seo-radar.yml` — ежедневный планировщик и публикация на Pages.
- `config/keywords.json` — фразы для мониторинга.
- `tests/` — тесты нормализации API, проверка регионов и работы с историей.
